4. Cryptography Test
**Difficulty:** Easy  
**Category:** Cryptography / Password Cracking  

**Objective:** decrypt basic Caesar shifts to find the Animal for the flag.

**Scenario:**
A list of passwords was leaked. Your mission is to decrypt them using dcode or doing the shifts for each character by hand.

**Instructions:**
- Open `Cipher_Shifts.txt`.
- Use an online decryption tool or do shifts by hand.
- Find the plain text password that stands out.

**Hint:** This animal is not on land.

Example: if the password is `password`, the flag is `FLAG{Animal}`
